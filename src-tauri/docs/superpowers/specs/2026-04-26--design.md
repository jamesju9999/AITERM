# SwiftRef API Java 呼叫範例 - 專案規格

## 1. 專案概述
建立一個簡單的 Java 應用程式範例，示範如何呼叫 SWIFT 的 SwiftRef API。

## 2. 功能需求

### 2.1 核心功能
- **F1**: 實作 OAuth 2.0 認證流程（Client Credentials Grant）
- **F2**: 呼叫 SwiftRef API 查詢 BIC 碼資訊（作為範例端點）
- **F3**: 解析 JSON 回應並顯示結果
- **F4**: 基本錯誤處理（HTTP 錯誤、網路異常）

### 2.2 技術選型
- **語言**: Java 11+（使用內建 HttpClient）
- **JSON 處理**: Jackson 或 Gson
- **建置工具**: Maven
- **依賴管理**: 最小化外部依賴

## 3. API 端點範例
根據 SWIFT 文件，主要使用：
- **認證端點**: `POST /oauth2/v1/token`
- **查詢端點**: `GET /v1/bicplus/{bic}` （查詢特定 BIC 碼）

## 4. 輸入/輸出

### 4.1 輸入
- API Consumer Key（從環境變數或設定檔讀取）
- API Consumer Secret（從環境變數或設定檔讀取）
- 欲查詢的 BIC 碼（例如：CHASUS33）

### 4.2 輸出
```json
{
  "bic": "CHASUS33",
  "institution_name": "JPMORGAN CHASE BANK, N.A.",
  "branch_information": "...",
  "city": "NEW YORK",
  "country": "US"
}
```

## 5. 驗收標準

### AC1: 認證成功
- **Given**: 有效的 Consumer Key 和 Secret
- **When**: 呼叫 OAuth token 端點
- **Then**: 成功取得 access_token

### AC2: API 查詢成功
- **Given**: 有效的 access token 和 BIC 碼
- **When**: 呼叫 BIC 查詢端點
- **Then**: 回傳該 BIC 的詳細資訊

### AC3: 錯誤處理
- **Given**: 無效的憑證或 BIC 碼
- **When**: 呼叫 API
- **Then**: 顯示清楚的錯誤訊息，不會造成程式崩潰

## 6. 限制與假設
- 假設使用者已有 SWIFT 開發者帳號
- 範例僅處理同步呼叫（不含非同步處理）
- 不實作 Token 快取機制（簡化版）
- 使用標準輸出顯示結果（不含 UI）

## 7. 安全性考量
- 敏感資訊（API Key/Secret）不可寫死在程式碼中
- 建議使用環境變數或外部設定檔
- HTTPS 連線驗證
