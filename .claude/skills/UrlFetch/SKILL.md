## 工具說明

`UrlFetch` 是以 .NET 9 實作的命令列工具，原始碼位於 `tools/UrlFetcher/`。它讓 Claude 能即時抓取任意網址的 HTML 頁面或 REST API 回應內容。

## 執行指令

```bash
dotnet run --project tools/UrlFetcher -- -u $ARGUMENTS --silent
```

若需進階用法，請依下列範本組合參數：

```
dotnet run --project tools/UrlFetcher -- -u <URL> [--silent] [-o <輸出檔案路徑>]
```

> **注意**：`--` 用於分隔 `dotnet run` 的參數與傳給工具本身的參數。

## 參數說明

| 參數 | 長格式 | 說明 | 必要 |
|------|--------|------|------|
| `-u` | `--url` | 要抓取的目標 URL（省略協定時自動補充 `https://`） | **是** |
| `-s` | `--silent` | 靜默模式：只輸出內容本身，不顯示狀態行。適合直接解析 | 否 |
| `-o` | `--output` | 將結果儲存至指定檔案路徑 | 否 |
| `-h` | `--help` | 顯示工具說明 | 否 |

## 操作步驟

1. **確認 URL**：確保使用者提供了明確的目標網址。若未提供，主動詢問。
2. **選擇模式**：
   - 若只需分析內容 → 加 `--silent` 取得純淨輸出。
   - 若需儲存快照 → 加 `-o <路徑>` 參數。
3. **執行命令**：使用 Bash 工具執行上述指令。
4. **解讀結果**：讀取輸出後，依使用者需求進行分析、摘要或引用。
5. **錯誤處理**：若工具回傳非零代碼，說明原因（URL 格式錯誤、網路失敗、HTTP 錯誤等）。

## 回傳碼

| 回傳值 | 說明 |
|--------|------|
| `0` | 成功抓取 |
| `1` | 錯誤（缺少 URL、網路失敗、HTTP 錯誤等） |

## 安全注意事項

- 僅抓取使用者明確提供或授權的 URL，**不主動猜測或生成 URL**。
- 避免將抓取到的敏感內容（如帳密、API Token）直接顯示於對話中。
- 本工具僅發送 GET 請求，不會修改遠端資料。

## 常見問題

**Q: 工具無法執行？** 確認 .NET 9 SDK 已安裝：`dotnet --version`

**Q: 抓取到空白內容？** 部分網站需要 JavaScript 渲染，UrlFetcher 僅取得靜態 HTML，可改用該網站的 API 端點。

**Q: HTTPS 憑證錯誤？** 本工具預設驗證 SSL，請確認目標網址憑證有效。
